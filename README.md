# libsm64-super-mario-64-DX-ChromiumPort
Super Mario 64 in a single HTML file that runs in your browser (on PC and Android). It uses libsm64 compiled to WebAssembly and requires your own ROM. It includes playable Luigi, Wario, and Yoshi, various skins, online cooperative multiplayer (in the style of sm64coop), and extras such as N. Sanity Island.
